##[[Habilitar - Deshabilitar configuraciones apache2]]
	- Habilitar --> a2enconf  [archivo] --> (a2)(en)(conf) [archivo]
	- Deshabilitar --> a2disconf [archivo] --> (a2)(dis)(conf) [archivo]

## PARA PERSONALIZAR UN ARCHIVO (por ejemplo el de erorr)
/etc/apache2/conf-available --> creas fichero --> editas fichero --> etc/apache2/conf-enabled --> a2enconf [archivo] (El archivo debe estar en /var/www/html para que funcione y reiniciar con "sudo systemctl reload apache2"

## Para redirigir al usuario a la página que yo quiero desde otra
/etc/apache2/conf-available --> miConf.conf (Redirect "/paginas" "/mispaginas") --> reiniciamos apache2


##################### HOSTS VIRTUALES (basados en nombre) #####################

1. Crear carpeta logs (/var/log/apache2)
2. Crear carpeta html (/var/www/html)
3. Copiar 000-conf para hacer fichero personalizado (/etc/apache2/sites-available)
4. Activar con a2ensite fichero.conf 
5. Reiniciar sudo systemctl reload apache2
6. Modificar los hosts con el host deseado (/etc/hosts --> "ip www.sadas.com")
__Escribe el contenido descargado en la terminal""wget -qO- http://www.alumnos.com""___
 --> Gracias a ServerName hace que apache2 sepa como relacionar la petición y el fichero conf
 --> Gracias a ServerAlias hace que nos redirija a la página (sin www) !!HAY QUE AÑADIR LA MISMA IP en /etc/hosts!!

=====================================================================================

para activar/desactivar Option indixes general en miConf.conf en conf-available
<Directory /var/www/html>
	Options -Indexes
</Directory>

Para activar en uno en concreto en /etc/apache2/sites-available/alumnos.conf
<Directory /var/www/html/alumnos>
	Options +Indexes
</Directory>
